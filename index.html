Life Skills with AI

Thirty-six free skills that teach Claude to do an everyday job well: plan a trip, pick a seat, host a dinner, check a quote, prepare for a meeting. Pick one, copy it into a chat, and go.

Quickest: try it in a chat

  1. Find a skill below and press Copy for a chat.
  2. Open Claude (or another AI chat) and paste.
  3. Add your own details at the end and send.

Keep it: install in Claude

  1. Press Download on a skill. You get one zip file.
  2. In Claude, open Customize, then Skills, and upload the zip.
  3. Turn it on. Claude now uses it whenever it fits.
Using Claude Code? Install all 36 at once

Run this inside Claude Code (version 2.1.275 or later):

/plugin install life-skills --marketplace amoluparab-prog/life-skills

Nothing matches that. Try a shorter word, or pick an area above.

Version 0.1.0. These skills were tested by AI sessions playing the user, not yet by people; each one's test record says what was not covered. Check anything that can change (prices, rules, forecasts) against the official source. The skills never book, pay or send anything for you.

The copy-into-a-chat version carries the same instructions, but a chat cannot run the small helper scripts two skills include, so those work best installed.
