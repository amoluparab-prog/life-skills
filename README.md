# Life Skills with AI

Everyday life skills for Claude: open-source skills for work, travel, family, money decisions and big ideas. "Skills" here means folders of instructions Claude loads to do a job well. Each one was built and checked with the same staged process: a brief, research from public sources, a draft, test prompts run by fresh sessions that had not seen the drafting, and an independent review scored against a fixed rubric. Every skill's test record, including what went wrong and what is still unproven, is published beside it.

## Install

Each skill is one folder under `skills/`.

**Claude (web or desktop app)**

1. Download this repository.
2. Zip the folder of the skill you want, so the archive contains `<skill-name>/SKILL.md` and not a bare `SKILL.md`. On macOS or Linux, from the `skills` folder: `zip -r seat-picker.zip seat-picker/`
3. In Claude, go to **Customize > Skills**, add a skill, upload the zip, and turn it on.

**Claude Code**

Copy the skill folder into your personal skills directory, so the file sits at `~/.claude/skills/<skill-name>/SKILL.md`:

```bash
git clone https://github.com/amoluparab-prog/life-skills.git
cp -r life-skills/skills/seat-picker ~/.claude/skills/
```

Install steps were checked against [Create custom skills](https://claude.com/docs/skills/how-to) on 21 November 2026.

## What to expect

These are version 0.1.0. They were tested by AI sessions playing the user, not yet by people, and each test record says plainly what was not covered. Anything a skill tells you that can change (forecasts, aircraft layouts, travel rules, prices) is looked up at the time and should be checked against the official source before you rely on it. The skills never book, pay or send anything for you.
