# Phase 3: Stays

Purpose: pick places to sleep by what the stay has to do, not by star rating.

## Steps
1. **Write down the job of each stay** in one line, from what they told you. A stay usually has to do some of these:
   - let everyone sleep well (quiet, beds for the real group, cot, air conditioning or heating for the season)
   - be near what matters (the meeting, the venue, the beach, the station, a relative)
   - fit the budget for the whole stay
   - stay flexible (free cancellation until when)
   - meet a need (step-free access, lift, kitchen for a diet or a baby, parking, late check-in)
   Ask if the job is not clear. A work trip and a family week want different things.
2. **Search live** with whatever tool the session has. Without one, say so and ask them to paste two or three candidates.
3. **Shortlist three**, different from each other, in one table:

   | | Option A | Option B | Option C |
   |---|---|---|---|
   | Place and area | | | |
   | Travel time to what matters (and how) | | | |
   | Room or bed set-up for this group | | | |
   | What it does well for this trip | | | |
   | Main drawback | | | |
   | Cancellation: free until (date, time), or non-refundable | | | |
   | Total price for the whole stay, with taxes and all fees | | | |
   | Checked on (date, source) | | | |

4. **Total price means total.** Include city or tourist tax, resort or cleaning fees, parking and breakfast if they need it. If a fee could not be confirmed, say so.
5. **Check the things that ruin stays:** check-in time against the flight's arrival, late-arrival arrangements, recent reviews that mention noise or building work, and whether the accessibility feature they need is confirmed in writing by the property and not just a filter on a booking site.
6. **Recommend one** in two sentences, saying what it gives up. Give the link. They book.

## Done when
Every night of the trip has a bed, booked by the traveller, or a deliberate gap they know about.

## Dated items to offer
Check-in and check-out with times, the free-cancellation deadline for each stay (set the reminder a day before it), any balance due date.
