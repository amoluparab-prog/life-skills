# Phase 2: Flights

Purpose: a shortlist the traveller can choose from in one read, with the trade-offs that matter, and a clear recommendation. They book.

## Steps
1. **Search live.** Use whatever flight search or web tool the session has. Prices and schedules are never quoted from memory. A "from" teaser price is not a search result. Without a real search, say so and ask them to paste the options they find, with for each: airline and flight numbers, dates out and back, where it changes and for how long, leave and arrive times, total price for everyone with bags, and whether it is one ticket. Record anything they leave out as "not given" and ask for it once.
2. **Shortlist up to three or four**, picked to be different from each other (for example: fastest, cheapest sensible, best arrival time); if the traveller brings two, compare those two in a few lines of prose or a table with only the rows that have data, and do not chase missing details of an option you are about to reject. If a pasted time or price looks wrong, say so and check it on the airline's page when you can. Otherwise show them in one table:

   | | Option A | Option B | Option C |
   |---|---|---|---|
   | Airline and route | | | |
   | Leaves / arrives (local times) | | | |
   | Total journey time | | | |
   | Connections and layover | | | |
   | Bags included (cabin, checked) | | | |
   | Change and refund rules | | | |
   | Total price for everyone, with bags and seats they need | | | |
   | Checked on (date, source) | | | |

3. **Look closely at each connection.** Rules of thumb, not official figures; the airline's and airport's own minimum connection times come first:
   - domestic to domestic, same terminal: about 1 to 1.5 hours
   - any international leg: 2 hours or more
   - changing terminal or airport, or collecting bags and going through immigration or security again: 3 hours or more
   - separate tickets: treat as two trips. If the first flight is late the second airline generally owes nothing, so leave many hours or stay overnight, and say this risk out loud.
   Add time for children, older travellers or anyone who needs assistance.
4. **Re-run the blockers for every connection country before recommending.** Now the route is known, look up that country's transit rules for this nationality: passport validity required (compare it with each passport date on the trip sheet), transit visa or authorisation, and rules on carrying their medicines. A passport that is fine for the destination can fail at the connection. Do this only for options still in the running, and when lookups are limited do the traveller's safety or medical need first, then passports, then the rest. If the passport date on the sheet is too coarse to decide ("July 2027"), ask for the exact expiry date, never the number. If the government pages do not say whether a rule applies to someone who stays airside, try the airline's travel-documents page or the connection country's border authority; if it is still unanswered, say "not verified", advise them to act as if the rule applies, and send them to the airline before they pay.
5. **Arrival time is part of the price.** Flag arrivals too late for public transport or hotel check-in, and departures that need a 3 a.m. start.
6. **Compare the real total.** Add bags, seat fees the group actually needs (families sitting together) and payment fees. A cheaper fare with no bag and no changes is often not cheaper.
7. **Recommend one**, in two sentences, saying what it gives up. Then give the link or the exact flight numbers and dates so they can book it themselves, preferably with the airline directly, which makes changes and disruption easier to sort out.
8. **Before they pay**, remind them to check that names match passports exactly, the dates and airports are right, and any assistance (wheelchair, bassinet, special meal, allergy arrangements) can be requested on this fare. If a passport is being renewed or may need to be, look up on the airline's page how passport details are added or changed after booking.
9. **Once they have booked**, suggest buying travel insurance now, so that cancellation is covered from the first payment (general advice; they should check the policy).

## Done when
The traveller has booked, or has chosen and knows how to book. Record flight numbers, dates and times in the trip sheet (no booking logins). Any blocker still open when they book (a passport date, a transit rule, an allergy arrangement) goes to the top of the next message and stays on the sheet until closed.

## Dated items to offer
Each flight with local times, when online check-in opens (look up for the airline), any fare hold or free-cancellation window that ends.
